Seven ways to draw the same three things per concern: Start, Best Confirmed (one run config, best across all concerns, measured on val) and Best Unconfirmed (the best single run config for that concern, measured on train). Best Unconfirmed only shows where it beats Best Confirmed, and it clears at every promotion round. Switch the moment to "after the gate" to see the reset.

For pass-rate evals the change is in percentage points; for cost and latency it is the relative change. Sample data on an invented agent.
