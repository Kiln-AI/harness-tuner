Activity feed

What the feed would say during one run, up to the middle of wave 4. It reads like a log: oldest at the top, newest at the bottom, scrolled to the latest line. It is plain on purpose: judge what is in it, not how it looks. Each line is built from an event or file the loop produces. Turn on sources to see which, and whether the data is available today.

Sample run on an invented freight-depot agent. All numbers are made up.
