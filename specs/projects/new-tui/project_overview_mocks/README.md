# Project overview mocks

Reference only. These are the early mocks from the design conversation that started this project. They are not final UI designs: the final UI is specified in `ui_design.md`, built for Textual, and is meant to be better than these.

Each file is a standalone HTML page. Open it in a browser. All data in them is invented sample data.

| File | What it is | Outcome |
|---|---|---|
| `01-component-sketchbook.html` | Round 1: 46 component sketches across 15 components, the expanded list of what a run could show, and a proposed visual language | Superseded. Later rounds pulled from C1·B (goal card), C2·A (twin gauges), C3·B (delta table), C4·B (small multiples) and C5·B (run timeline) |
| `02-activity-feed.html` | Content mock of the log, each line traced to the wave-log event it comes from | Accepted with one change: log order, newest at the bottom |
| `03-results-rows-rejected.html` | Results as one row per concern with a stacked bar, intervals, parents and notes | Rejected: too much information, unreadable |
| `04-results-renders.html` | Seven renders of Results (rows, split bars, column chart, tables, cards, tiles) and five legend styles | Render F (cards) chosen |
| `05-results-cards-f.html` | Render F reflowing at 80, 100, 130 and 160 columns, key on the header line | Chosen for Results |
| `06-experiments-sprint.html` | Content debate for the experiments section and five layouts (A–E) | Layout C (cards) chosen; finished cards keep their size and place |
| `07-run-screen.html` | Whole-screen comp, pass 3: title bar, goal, time and spend, run timeline, Results (F), experiments (C), log, across the run's modes | Latest whole-screen reference |
